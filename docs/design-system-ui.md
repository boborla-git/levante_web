# Levante / Ravioli - Mini Design System CSS

## Regole base

- Set icone unico: Line Awesome.
- Azioni principali: `.btn .btn-primary`.
- Azioni alternative/evidenziate: `.btn .btn-secondary` oppure `.btn .btn-warning`.
- Azioni secondarie: `.btn .btn-outline-primary`.
- Azioni distruttive: `.btn .btn-danger` oppure `.btn .btn-outline-danger`.
- Azioni in tabella: sempre `.btn .btn-sm` con icona + testo.
- Link testuali: solo per navigazione non operativa.

## Esempi

```html
<button class="btn btn-primary">
    <i class="la la-save"></i> Salva
</button>

<a class="btn btn-outline-primary" href="utente_nuovo.php">
    <i class="la la-user-plus"></i> Nuovo utente
</a>

<button class="btn btn-outline-danger">
    <i class="la la-trash"></i> Elimina
</button>
```
